Get the app onto your phone

You'll give the app a free web address with Cloudflare Pages. Cloudflare copies the code from your GitHub repo, builds it, and hosts it. After that you open the address on your phone once and add it to your home screen.

About 10–15 minutes Free Do it on your computer
0 of 6 done
Your data stays private. The web address only serves the app itself. Your defects, photos and costs are saved on each device, and nobody who visits the address can see them.

  1. Create a free Cloudflare account

    Go to dash.cloudflare.com/sign-up and sign up with your email. Confirm the email they send you.

    If Cloudflare asks you to add a website or domain, skip it. You don't need a domain; Cloudflare gives you a free .pages.dev address.

  2. Start a new Pages project

    • In the left menu open Workers & Pages (it may sit under Compute).
    • Click Create (or Create application).
    • Choose the Pages tab. If you only see Workers options, look for a link like Looking to deploy Pages? Get started.
    • Pick Import an existing Git repository (sometimes labelled Connect to Git).

    Cloudflare changes these labels from time to time. The idea is the same: make a Pages project that connects to Git, not a Worker.

  3. Connect GitHub and choose the repo

    • Click Connect GitHub. A GitHub window opens.
    • Choose Only select repositories, pick ngerver1/car, then Install & Authorize.
    • Back in Cloudflare, select car and click Begin setup.

    Giving access to just this one repo keeps Cloudflare away from anything else in your GitHub account.

  4. Fill in the build settings

    Enter these exactly. Use the copy buttons to avoid typos.

    Project namer35-log
    Production branchclaude/nice-goldberg-sxfr33
    Framework presetNone
    Build commandnpm run build
    Build output directorydist

    Then open Environment variables (advanced) and add one variable:

    Variable nameNODE_VERSION
    Value22

    The production branch is the branch where the app's code lives right now. The Node version makes Cloudflare build with the same tools the app was tested with. Leave the root directory blank.

  5. Deploy and open the address

    • Click Save and Deploy. The build log runs for a minute or two and should end with Success.
    • Your address is shown at the top, something like https://r35-log.pages.dev. If that name was taken, Cloudflare adds a few extra letters.
    • Open the address on your computer. You should see the dashboard with 74,689 km on the odometer tile.

    From now on, each time I push new work to this branch, Cloudflare rebuilds the app on its own. The app on your phone updates the next time you open it with signal.

  6. Add it to your phone's home screen

    Open the same address on your phone, wait a few seconds for it to load fully, then:

    iPhone

    1. Open the address in Safari (not Chrome).
    2. Tap the Share button.
    3. Tap Add to Home Screen, then Add.

    Android

    1. Open the address in Chrome.
    2. Tap the ⋮ menu.
    3. Tap Install app or Add to Home screen.

    To check it works offline: open the app from the home-screen icon once, switch on airplane mode, close it, and open it again.

    On iPhone, always open the app from the home-screen icon rather than a Safari tab. iOS keeps the app's saved data more reliably that way.

If something goes wrong

I can't find the Pages option

Cloudflare has been merging Pages into Workers, so the menu moves around. Search the dashboard for "Pages", or tell me what you see on screen and I'll point you to the right button.

My repo isn't in the list

The GitHub connection only covers the repos you picked. In GitHub go to Settings → Applications → Cloudflare Workers and Pages → Configure, and add ngerver1/car.

The build failed

Open the build log, copy the last 20 or so lines, and paste them to me. The usual cause is a mistyped build command or output directory, or the missing NODE_VERSION variable.

The page is blank or shows an old version

Reload once or twice. The app saves itself for offline use, and the first reload after an update can still show the previous version.

When you're done, send me the address Cloudflare gave you. I'll check it's serving the latest build and then start milestone 4 (service schedule and due list).
