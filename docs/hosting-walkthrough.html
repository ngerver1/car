Get the app onto your phone

The app is hosted free by GitHub Pages, straight from your ngerver1/car repo. I've already added the workflow that builds and publishes it. You switch Pages on once, then add the app to your phone's home screen.

About 5–10 minutes Free Only your GitHub account
0 of 4 done
Your data stays private. The car repo and the web address only hold the app's code. Your defects, photos and costs stay on each device for now. From milestone 7 they'll sync to a separate private repo, car-data, which you'll set up then.

  1. Switch on GitHub Pages

    • Open github.com/ngerver1/car/settings/pages (or the repo's Settings tab, then Pages in the left menu).
    • Under Build and deployment, set Source to GitHub Actions.

    That's the whole setting; there's no Save button. It tells GitHub to publish whatever the repo's deploy workflow builds.

  2. Run the deploy

    • Open the Deploy to GitHub Pages workflow in the repo's Actions tab.
    • Click Run workflow, keep the branch shown, and click the green Run workflow button.
    • Wait about 2 minutes for the run to show a green tick.

    A run probably already happened when I pushed, before Pages was switched on, so it will show a red cross. That's expected; this new run replaces it. From now on every push I make deploys on its own.

  3. Open the app on your computer

    Your app's addresshttps://ngerver1.github.io/car/

    Open ngerver1.github.io/car. You should see the dashboard with 74,689 km on the odometer tile.

    If GitHub shows a 404 page, wait a minute and reload. The first publish can take a moment to appear.

  4. Add it to your phone's home screen

    Open the same address on your phone, wait a few seconds for it to load fully, then:

    iPhone

    1. Open the address in Safari (not Chrome).
    2. Tap the Share button.
    3. Tap Add to Home Screen, then Add.

    Android

    1. Open the address in Chrome.
    2. Tap the ⋮ menu.
    3. Tap Install app or Add to Home screen.

    To check it works offline: open the app from the home-screen icon once, switch on airplane mode, close it, and open it again.

    On iPhone, always open the app from the home-screen icon rather than a Safari tab. iOS keeps the app's saved data more reliably that way. Until sync arrives, each device keeps its own records, so pick one device for real entries for now.

If something goes wrong

There's no Run workflow button

Reload the Actions page. If it's still missing, open the latest red run and click Re-run all jobs instead.

The deploy step says the branch isn't allowed

Go to Settings → Environments → github-pages. Under Deployment branches and tags, add claude/nice-goldberg-sxfr33 (or choose No restriction), then re-run the workflow.

The run failed on "npm test" or "npm run build"

Open the failed step, copy the last 20 or so lines, and paste them to me.

The page is blank or shows an old version

Reload once or twice. The app saves itself for offline use, and the first reload after an update can still show the previous version.
